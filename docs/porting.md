# 移植与标定

## 必需适配层

该代码依赖 STM32 HAL、FreeRTOS、CMSIS-DSP 及项目级数据接口。移植方应提供：

- 8 个电机的 CAN 接收、发送和反馈数据；
- 云台 yaw 角、遥控器速度指令及模式指令；
- 必要的在线检测和功率限制数据；
- 周期性调用 `chassis_task` 的 FreeRTOS 任务环境。

## 标定顺序

1. 固定机械零位，记录每个舵向编码器读数，填入 `Forward_L_ecd` 等宏。
2. 验证四个舵向电机的正方向；反向时在 CAN 输出或反馈层统一处理。
3. 验证四个驱动轮的正方向与轮组编号。
4. 填写轮组半径、模块到中心距离和方位角。
5. 先关闭驱动轮输出，单独调舵向位置环；再调驱动轮速度环。

## 建议测试记录

发布或参评前，建议记录并附图：静态零位误差、90°阶跃响应、定速横移、原地旋转、模式切换和 CAN/裁判系统离线保护。每条记录应注明固件 commit、参数、负载和测试日期。
