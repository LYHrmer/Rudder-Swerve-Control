# 软件架构与数据流

```text
遥控器 / 云台 / 上板 CAN 指令
              │
              ▼
       chassis_behaviour
              │  选择跟随、舵轮跟随、旋转或失能模式
              ▼
          chassis_task
    ┌─────────┼─────────┐
    ▼         ▼         ▼
速度坐标变换  四轮运动学  功率限制
    │         │         │
    └────────►四个舵向优化◄──── 电机编码器反馈
                    │
                    ▼
          位置环 + 速度环 + CAN 发送
```

`chassis_task` 是 2 ms 周期的控制入口。每周期按以下次序执行：更新反馈、选择模式、生成速度命令、计算四轮目标、应用最优角和三次余弦补偿、执行 PID，最后发送 CAN 电流命令。

## 与整车工程的边界

本仓库仅发布底盘控制层。以下模块由集成方提供：STM32 HAL、FreeRTOS 任务启动、遥控器解析、云台/裁判系统数据、离线检测、超级电容及具体 CAN 驱动。
